# 🧠 AstraWear Second Brain

Your daily ideas, captured before they escape — and organized so they actually turn into features.

This folder is an **Obsidian vault**. Obsidian is a free app that opens a folder of plain markdown notes and links them together. Nothing here is locked in — they're just `.md` text files you own forever.

---

## The workflow (keep it simple)

**1. Capture** → Whenever an idea hits, drop one line in `00-Inbox/Inbox.md`. Don't organize, don't judge. Just get it out of your head.

**2. Organize** → Once a day (or weekly), move inbox lines into `01-Ideas/` as proper notes, or add them to `03-Roadmap/`.

**3. Distill** → In each idea note, sharpen it: what is it, why it matters, how it could work.

**4. Use** → When you sit down to build, pull from `03-Roadmap/Roadmap.md`.

The whole point: **capture fast, organize slow.** A second brain fails when capturing is hard, so keep the Inbox stupidly quick.

---

## The Claude loop 🤝

This is the part from the reel. You don't organize alone:

- **Brain-dump** everything into `00-Inbox/Inbox.md` — messy is fine.
- Then in Cowork, say: *"process my Inbox — sort these into idea notes and update the roadmap."*
- I'll expand the good ones, file them, flag duplicates, and surface next steps.

You capture. I organize. That's the system.

## Folder guide

| Folder | What goes here |
|--------|----------------|
| `00-Inbox/` | Raw capture. Fast, messy, unsorted. Empty it regularly. |
| `01-Ideas/` | Developed ideas, one note each. Start in `_Ideas Index.md`. |
| `03-Roadmap/` | What to build and when — Now / Next / Later. |
| `04-Research/` | Inspiration, competitors, design references. |
| `05-Daily/` | One note per day. Optional, but great for tracking momentum. |
| `templates/` | Copy these when making a new idea or daily note. |

## Open this in Obsidian (2 minutes)

1. Download Obsidian (free) from **obsidian.md**.
2. Open it → **"Open folder as vault"** → select this `second-brain` folder.
3. Settings → Core plugins → turn on **Templates** and **Daily notes**.
4. Settings → Templates → set the template folder to `templates`.
5. Done. Start typing in `00-Inbox/Inbox.md`.

Tip: `[[double brackets]]` link notes together. `#tags` group them. Click the graph icon to see your brain as a web.
