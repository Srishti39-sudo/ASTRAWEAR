# My Skill Tracks (what AstraWear is actually teaching me)

Tags: #skills #career

## The key insight
**Styling expertise and LLM evals are not two separate skills — the first is the rubric for the second.**
To judge whether the AI gave a good outfit, you need to know what a good outfit is. Most people doing LLM evals have no domain knowledge; they can only check format and safety. Having **both** is the rare, hireable combination.

---

## Track 1 — Fashion styling (now, until the internship)
Go deep and niche.
- Body shape systems (proportion, silhouette, balance)
- Color theory / seasonal analysis — feeds the astro palette logic
- Occasion dressing: formality levels, dress codes, impression goals
- Fabric, drape, fit vocabulary
- Practice: style real people, document before/after and the reasoning
- Deconstruct working stylists — *why* does that outfit work?

✅ Done when: I can explain in precise language why an outfit works or fails.

## Track 2 — LLM evals (next)
My own app is the perfect testbed — I already have real outputs to judge.
- Build a **rubric** from Track 1: occasion-appropriate? only uses items in the stated wardrobe? palette consistent with the Venus/Rising reading? specific vs generic?
- Build a **golden set**: 30–50 test cases with expected qualities
- **Score** the outputs, find failure patterns
- **Tune the prompts**, re-score, measure the improvement
- Write it up — that's a portfolio piece

✅ Done when: I can show "before vs after" numbers on my own AI's quality.
