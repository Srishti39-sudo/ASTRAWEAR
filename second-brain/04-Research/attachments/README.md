# Reference images — drop them here

Images pasted into chat aren't saved automatically. Save the ones you want to keep **here**, in this folder.

## How
1. Right-click the image → **Save Image As…**
2. Save into this `attachments` folder.
3. In Obsidian, embed it in any note with: `![[filename.png]]`
